# ROS2 自主导航小车硬件电气接线图与引脚分配手册

## 一、 系统供电方案 (Power Distribution)

* **动力主电源**：3S 动力锂电池组 (11.1V ~ 12.6V, 2200mAh ~ 3000mAh, 25C+)。
* **电源分支 1 (高压动力路)**：
  * 直连 TB6612 / A4950 电机驱动板的 `VM` 和 `GND` 引脚（提供大电流电机驱动）。
* **电源分支 2 (5V/5A 降压路)**：
  * 经大功率降压模块 (如 XL4015 或 TPS5450) 降压至稳压 5.0V / 5A。
  * 分流为泰山派 RK3576、瑞芯微 RK3566 开发板的 Type-C/排针 5V 接口供电。
* **下位机供电**：STM32F407 可通过降压 5V 接入 `5V` 引脚，或通过 USB-CDC 与上位机共地供电。

## 二、 STM32F407 核心引脚映射表

| 模块 | 功能说明 | STM32 硬件外设 | 推荐 GPIO 引脚 |
| :--- | :--- | :--- | :--- |
| **左电机 PWM** | 速度调速 (0~1000) | TIM1_CH1 | PA8 |
| **左电机方向 1** | 方向控制 IN1 | GPIO_Output | PC4 |
| **左电机方向 2** | 方向控制 IN2 | GPIO_Output | PC5 |
| **右电机 PWM** | 速度调速 (0~1000) | TIM1_CH2 | PA9 |
| **右电机方向 1** | 方向控制 IN3 | GPIO_Output | PB0 |
| **右电机方向 2** | 方向控制 IN4 | GPIO_Output | PB1 |
| **左轮编码器 A 相** | 正交脉冲通道 A | TIM2_CH1 | PA0 |
| **左轮编码器 B 相** | 正交脉冲通道 B | TIM2_CH2 | PA1 |
| **右轮编码器 A 相** | 正交脉冲通道 A | TIM3_CH1 | PA6 |
| **右轮编码器 B 相** | 正交脉冲通道 B | TIM3_CH2 | PA7 |
| **与 RK3576 通信** | 串口发送 TX | USART1_TX | PA9 / PB6 |
| **与 RK3576 通信** | 串口接收 RX | USART1_RX | PA10 / PB7 |

## 三、 泰山派 RK3576 外部接口分配

1. **USB 3.0 接口 1**：连接激光雷达 (RPLIDAR A1/LD19)。
2. **USB 2.0 / Type-C 接口 2**：连接 STM32F407 串口/USB-CDC。
3. **千兆以太网口 / Wi-Fi**：与 RK3566 车机屏在同一局域网组网，跑 ROS2 DDS 通信。
